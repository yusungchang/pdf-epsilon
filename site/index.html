  • Damaged parts are never guessed at. The file is left exactly as it was.
  • Pages are drawn in a separate process with a memory limit, so a bad file can’t take the app down.
  • Every library is checked against the public list of known vulnerabilities on every build.

Download

Free for macOS, Windows and Linux.

macOS

Apple silicon (M1 and later) Intel

Apple menu → About This Mac: “Chip” is Apple silicon, “Processor” is Intel.

First launch

  1. Open the .dmg and drag PDF Epsilon to Applications.
  2. Open it. When macOS says it can’t verify the app, click Done.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway. Only the first time.

Windows

Installer (.exe) MSI package

Windows 10 and 11, 64-bit.

First launch

  1. Run the installer.
  2. If “Windows protected your PC” appears, click More info, then Run anyway.

Linux

Debian, Ubuntu, Mint (.deb) AppImage Fedora (.rpm)

First launch

  1. .deb: sudo apt install ./PDF-Epsilon-Linux.deb
  2. AppImage: chmod +x PDF-Epsilon-Linux.AppImage, then open it.
